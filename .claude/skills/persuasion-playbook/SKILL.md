# Persuasion Playbook — Behavioral Science Applied to Conversion

You apply Robert Cialdini's 7 principles of influence + behavioral economics
to web design. You never use these to manipulate — only to remove friction
between users and decisions they already want to make.

## Cialdini's 7 — Web Application Moves

### 1. Reciprocity
*Give first, ask second.*
- **Free audit / teardown / playbook** before the call ask (your existing pattern)
- Specific number of tips: "47 conversion fixes" beats "tips for converting more"
- Show the deliverable *preview* before they convert (sample audit PDF page)

### 2. Commitment / Consistency
*Get a small yes, escalate.*
- Start funnels with a yes/no question users can't say no to ("Do you want more revenue from your existing traffic?")
- Multi-step forms with progress bars trigger completion bias (Zeigarnik effect)
- Public commitments stick: "I want to grow by 30% this quarter" → harder to back out

### 3. Social Proof
*Show what people like them are doing.*
- "300+ Shopify stores trust us" — specific number + specific niche > vague
- Logo walls grouped by industry (you have this — dental, ecom, weight loss)
- Recency badges: "Joined this month: 12 new clients"
- Review counts visible: "Rated 4.9 ★ across 142 reviews"

### 4. Authority
*Borrow credibility.*
- Founder bio with credentials, not photos with quotes
- Press mentions ("As seen in Forbes / Shopify+") — only if real
- Certifications (Shopify Partner, Google Premier Partner)
- Frameworks named after you ("The Convertt CRO Method")

### 5. Liking
*People buy from people they like.*
- Founder face above the fold on key pages
- Conversational copy that reads like a human, not a brochure
- Specific shared context: "If you're a dental practice in the UK with 2+ chairs…"
- Self-aware humor builds rapport (used sparingly)

### 6. Scarcity
*What's rare is valuable.*
- Cohort-based intake ("Q1 onboarding closes Friday")
- Capacity-based ("3 client spots left this quarter")
- Time-bound bonuses ("Book this week, get the brand audit free")
- NEVER fake scarcity. Users smell it instantly. Long-term trust > short-term lift.

### 7. Unity
*Tribal identity.*
- "We're a CRO agency for *premium* brands" — defines an in-group
- "If you're tired of agencies that just make it pretty, we're for you"
- Anti-positioning: explicitly NOT for X creates strong identification for non-X

## Behavioral Economics Add-ons

### Loss Aversion
- "Stop losing $X/month to a leaky funnel" > "Earn $X/month more"
- Losses feel 2× more painful than equivalent gains feel good

### Anchoring
- Show the *highest* package first on pricing pages
- "Most agencies charge $50K. We deliver the same outcome for $25K."

### Default Effect
- The default choice gets picked 70%+ of the time
- Highlight your middle/preferred tier with a "Most Popular" badge

### Decoy Effect
- 3 tiers > 2 tiers. Middle option converts 2× when flanked by a clearly worse + clearly more expensive option.

### Endowment Effect
- "Imagine your dashboard at 5% CVR…" — getting them to mentally own the outcome
- Free trials work because giving up what you "have" hurts

### Cognitive Fluency
- Easier-to-read = more believable. Use larger type, more whitespace, simpler sentences.
- Rhyming claims feel truer ("if it doesn't fit, you must acquit")
- Round numbers feel less precise (302 specific patients > "about 300")

## Application Process

When designing any persuasive surface:

1. **Identify the decision** you want the user to make
2. **List the 2–3 reasons they'd hesitate** (cost, time, trust, fit, risk)
3. **Map each hesitation to a principle** above
4. **Pick concrete moves** — don't try to deploy all 7, pick 3 that hit hardest
5. **Verify with the user's voice** — would they buy this without flinching?

## Ethical Floor

Never use persuasion against the user's interests. The test:
> Would I be happy if my smartest friend bought this after seeing this page?

If yes → ship. If no → fix the offer, not the persuasion.
